# Rails Testing Methodology & Practice Guide

A hands-on guide to writing and running tests in a Ruby on Rails application — covering environment setup, unit tests, integration tests, background job tests, system tests, and the Rails-specific patterns and anti-patterns that keep a test suite fast, reliable, and genuinely useful.

## Purpose

This guide exists to give the team a consistent, practical playbook for testing Rails applications. Rather than just explaining testing theory, it focuses on *how* to actually set up, write, and run tests day to day — the tools to use, the patterns to follow, and the mistakes to avoid. Use the navigation to jump to the layer you're working on, whether that's model specs, request specs, job specs, or system tests.

## Audience

Developers building features in the Planned Service module and future modules. Some Rails/RSpec familiarity is assumed, but each section is written to be followed on its own without needing to read the others first.
